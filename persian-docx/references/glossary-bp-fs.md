# واژه‌نامه‌ی طرح کسب‌وکار و مطالعه‌ی امکان‌سنجی

طرح کسب‌وکار (BP) توضیح می‌دهد کسب‌وکار چگونه مشتری جذب می‌کند، درآمد به دست می‌آورد، اداره و تأمین مالی می‌شود. مطالعه‌ی امکان‌سنجی (FS) بررسی می‌کند یک گزینه تحت چه شرایطی از نظر بازار، اجرا، مقررات و مالی قابل پیشبرد است. فصل‌های مشترک را متناسب با هدف سند بنویس. صورت انگلیسی ستون اول برای پانویس نخستین کاربرد است؛ قواعد [واژه‌گزینی گزارش](report-terminology.md) و [واژه‌نامه‌های تکمیلی](glossary-cross-domain.md) را هم اعمال کن.

## طرح کسب‌وکار

| انگلیسی | فارسی پیشنهادی | کنترل کاربرد |
|---|---|---|
| Business Plan (BP) | طرح کسب‌وکار | با «مدل کسب‌وکار» یکسان نیست. |
| Executive Summary | خلاصه‌ی مدیریتی | یافته‌ی اصلی، نیاز به منابع و تصمیم مورد انتظار. |
| Business Model / Revenue Model | مدل کسب‌وکار / مدل درآمدی | دومی روش ایجاد درآمد است، نه کل سازوکار کسب‌وکار. |
| Value Proposition | ارزش پیشنهادی به مشتری | مزیت ملموس همان مشتری؛ نه شعار فروش. |
| Target Market / Customer Segment | بازار هدف / بخش مشتریان | بازار هدف، انتخاب کسب‌وکار است؛ بخش، گروهی با ویژگی مشترک. |
| Competitive Advantage | مزیت رقابتی | مبنای مقایسه با رقیب یا گزینه‌ی جایگزین. |
| Go-to-Market Strategy | راهبرد ورود به بازار | عرضه، جذب مشتری، قیمت و کانال را بنا بر دامنه‌ی متن روشن کن. |
| Sales Channel / Distribution Channel | کانال فروش / کانال توزیع | مسیر ثبت فروش و مسیر رساندن کالا لزوماً یکی نیستند. |
| Sales Forecast / Sales Target | پیش‌بینی فروش / هدف فروش | مقدار مورد انتظار را از هدف مدیریتی جدا کن. |
| Funding Request / Use of Funds | درخواست تأمین مالی / محل مصرف منابع | مبلغ، زمان و کاربرد پول را تفکیک کن. |
| Unit Economics | درآمد و هزینه در سطح هر واحد | واحد واقعی را نام ببر: سفارش، مشتری یا محصول. |
| Operating Model | الگوی اداره‌ی عملیات | نقش‌ها، فرایندها و ظرفیت اجرا را مشخص کن. |

## مطالعه‌ی امکان‌سنجی

| انگلیسی | فارسی پیشنهادی | کنترل کاربرد |
|---|---|---|
| Feasibility Study (FS) / Pre-feasibility Study | مطالعه‌ی امکان‌سنجی / مطالعه‌ی پیش‌امکان‌سنجی | دومی بررسی مقدماتی برای غربال گزینه‌ها و تعیین کار تکمیلی است. |
| Market Feasibility / Technical Feasibility | امکان‌سنجی بازار / امکان‌سنجی فنی | تقاضای قابل اثبات را از ظرفیت و امکان اجرا جدا کن. |
| Financial Feasibility / Economic Appraisal | امکان‌سنجی مالی / ارزیابی اقتصادی | جریان وجوه طرح را از هزینه‌ها و منافع اقتصادی برای جامعه تفکیک کن. |
| Alternatives Analysis / Base Case | مقایسه‌ی گزینه‌ها / سناریوی پایه | مفروضات مشترک و معیار مقایسه را بیان کن. |
| Design Capacity / Operating Capacity | ظرفیت طراحی / ظرفیت عملیاتی | نام و مبنای ظرفیت مصوب طرح را حفظ کن؛ با تولید یا فروش واقعی یکی نیست. |
| Capacity Utilization Rate | نرخ بهره‌برداری از ظرفیت | مخرج، دوره و مبنای اندازه‌گیری را تعیین کن. |
| Working Capital / Cash Conversion Cycle (CCC) | سرمایه در گردش / چرخه‌ی تبدیل وجه نقد | یکی مبلغ است و دیگری مدت؛ اصطلاح محلی «چرخه‌ی نقدینگی» را فقط با تعریف مشخص به کار ببر. |
| Break-even Point / Contribution Margin | نقطه‌ی سربه‌سر / حاشیه‌ی مشارکت | دومی فروش منهای هزینه‌ی متغیر است؛ سربه‌سر را به واحد یا ریال مشخص کن. |
| Simple Payback Period / Discounted Payback Period | دوره‌ی بازگشت ساده / دوره‌ی بازگشت تنزیل‌شده | مبنای جریان نقد و سرمایه‌گذاری را تعریف کن. |
| Net Present Value (NPV) / Internal Rate of Return (IRR) | ارزش فعلی خالص / نرخ بازده داخلی | دیدگاه تحلیل، دوره و مفروضات جریان نقد را گزارش کن. |
| Sensitivity Analysis | تحلیل حساسیت | مشخص کن چه فرض‌هایی تغییر کرده‌اند و چه فرض‌هایی ثابت مانده‌اند. |
| Scenario Analysis | تحلیل سناریو | وضعیت‌های متفاوت را با مجموعه مفروضات سازگار مقایسه کن. |
| Stress Testing | ارزیابی طرح در سناریوهای بدبینانه | شرایط شدید اما قابل‌تصور و شاخص تاب‌آوری طرح را مشخص کن. مثال: اثر هم‌زمان تغییر نرخ ارز، افت فروش و تأخیر تأمین بر نقدینگی. |
| Incremental Analysis | بررسی آثار افزوده‌ی هر گزینه | درآمد، هزینه و جریان نقد اضافه نسبت به حالت پایه یا بدون آن گزینه را بسنج. |

مراجع کنترل مفهوم: [راهنمای طرح کسب‌وکار SBA](https://legacy.sba.gov/business-guide/plan-your-business/write-your-business-plan)، [راهنمای مطالعات صنعتی UNIDO](https://www.unido.org/sites/default/files/files/2021-02/manual_for_the_preparation_of_industrial_feasibility_studies.pdf)، [شرح سناریوی نامساعد و آزمون تنش BIS](https://www.bis.org/publications/fsi-summary-stress-testing-executive-summary). این مراجع صورت انگلیسی و حدود مفهوم را روشن می‌کنند؛ عبارت‌های فارسی، پیشنهاد ویرایشی متناسب با مخاطب‌اند.
